### 🧠 What I'm building

**E-Invoicing Agent** — a multi-functional AI agent for Malaysian SME owners, built around the MyInvois / LHDN e-invoicing mandate.
- 🔐 Tokenized PII architecture, positioned as long-term infrastructure for a future cash-flow credit scoring layer
- 💬 Autonomous multilingual receivables chasing
- 📊 Payment behaviour scoring + 13-week cash-flow forecasting, designed as one closed demo loop
- ⚖️ PDPA Amendment 2024 compliance as the core sales hook for SMEs
